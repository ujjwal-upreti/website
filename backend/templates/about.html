About SneakerStore

This project implements the exact Use Case Diagram and Level-1 DFD you provided for a Shoe / Sneaker E-Commerce System.

Roles (Customer, Shopkeeper, Staff, Admin), processes (1.0–8.0), and data stores (D1–D6) are fully mapped into working Flask code.

System Roles

  • Customer – View shoes, Add to cart, Place order, Make payment, Generate invoice, Profile
  • Shopkeeper – Add stock, Check daily sales report
  • Staff – Manage product, payment, customer (no admin rights)
  • Admin – Manage users and full application
